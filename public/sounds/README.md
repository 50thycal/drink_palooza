# Soundboard recordings (optional)

The soundboard synthesises every sound in the browser (`lib/sounds.ts`).
To use a real recording instead, drop an MP3 here with the sound's key as
its name and push. Any file that's missing falls back to the synth.

| File | Button |
|------|--------|
| `womp.mp3` | 🎺 Womp womp (sad trombone) |
| `rimshot.mp3` | 🥁 Ba-dum-tss |
| `applause.mp3` | 👏 Applause |
| `airhorn.mp3` | 📯 Air horn |
| `drumroll.mp3` | 🪘 Drumroll |
| `boom.mp3` | 💥 Explosion |

Keep them short (under ~5 s) and only use audio you have the rights to,
such as CC0 / public-domain recordings or your own.
